EU AI Act Research Desk

A retrieval-augmented generation system for asking questions about a versioned legal corpus and inspecting the evidence behind the answer.

From question to cited answer

  1. 01 · ASK

    Resolve the question

    The browser turns supported follow-ups into standalone questions and asks for clarification when the reference is unclear.

  2. 02 · RETRIEVE

    Find relevant provisions

    Weighted passage search and provision lookup use a pinned EUR-Lex corpus of articles, annexes and recitals.

  3. 03 · GENERATE

    Draft from evidence

    A Vercel function sends verified passages to OpenAI. The model returns structured claims with source IDs.

  4. 04 · VALIDATE

    Check the draft

    Code checks source IDs and selected constraints. A model review then checks grounding and material exceptions.

  5. 05 · CITE

    Show the supporting text

    The server attaches exact quotes and official links. Readers can expand a citation to see its surrounding provision.

  6. 06 · FALL BACK

    Keep the evidence available

    If generation is unsupported or unavailable, the desk shows retrieved passages or abstains when evidence is insufficient.

How I tested it

Retrieval cases

15/15

Hosted smoke cases

Nine cited answers, five abstentions, and one empty-input check in the recorded run.

Regression coverage

Node.js, pytest and Playwright cover citation contracts, keyboard and mobile flows, and visual changes in GitHub Actions.

A failure worth discussing

An early model answer cited Article 5 but reversed a prohibition. That led to a test that fails even when the citation and expected keywords are correct. The test covers the observed error pattern. Broader legal accuracy still requires expert review.
